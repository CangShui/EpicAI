# EpicAI 项目验收测试书

## 1. 测试目的

验证 EpicAI 是否具备：

* OpenAI API 基础兼容性
* Chat Completions Streaming
* Responses API Streaming
* Infinite Echo
* 多模态输入
* 文件管理
* 会话实时管理
* 人工接管
* 故障注入
* 自定义错误
* 网络异常模拟
* 模型动态管理
* 长连接稳定性
* 资源保护

---

# 2. 验收原则

测试结果分：

```text
PASS
FAIL
PARTIAL
BLOCKED
```

任何 P0 测试存在 FAIL：

> EpicAI 不允许判定为 MVP 完成。

施工方必须提供实际：

* curl 输出
* 自动测试结果
* API Response
* 浏览器后台截图或录屏
* 必要的服务日志

不能仅用文字声明“已经完成”。
